# packages

Do not install, remove, upgrade or downgrade any packages (system-wide or within the project).

Do not make any system-wide changes (eg, OS level changes). Let me know if something needs to be changed on the system
and I will do it.

Let me know if there are any external projects or packages that would speed development. No need to re-invent the wheel.
However, let me make the decision and install them.

# files

RUNS.md → tracks notable runs and their final results
SETUP.md → contains 1-time initialisation/setup commands, tasks, caveats, etc...

# directories

apps
cache → transient files used or generated by the project
cache/metrics → contains metric files from notable historic runs
roofline → measured roofline data for target GPUs
src → core nanochat source code
external → external packages and dependencies

# testing code changes

After making code changes, if you need to run a test that uses the GPU, run the shorted test reasonably possible. For
example, usually a simple d4 or d12 test will suffice.

Leave the longer running tests to me.

Always check to see if the GPUs are in use before running a test that will hit the GPU.
